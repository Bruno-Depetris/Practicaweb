# Practicaweb

Este es un recorrido completo en el cual tengo muchas expectativas para comprender como funciona una SPA completa. 
Mi objetivo es usarlo solamente HTML,CSS Y JS, ya que pretendo que este proyecto sirva de referencia para hacer futuros sistemas sin la necesidad de ningun framework por lo tanto, el dia que necesite de un framework voy a saber muy bien como funciona el javascript que hay por detras.

Para comenzar con este sistema uso claude, pero en este caso la IA , no es invasiva, no toca el codigo directamente, me ayuda con mi objetivo, no lo uso como muleta, sino como la herramienta para la que fue creada. El objetivo del asistente es una meta clara, ayudarme , mientras tanto yo por mi lado busco sacar mis propias conclusiones.

Como generalmente el back lo hago en otra tecnologia la cual ya tengo clara, utilizaremos una API llamada https://dummyjson.com/ , la cual viene completa y me sirve para practicar la creacion de sistemas de gestion.
